# ZeroAI videos

Product videos, served with GitHub Pages.

- [ZeroAI Studio: the connected STEM classroom](https://zeroai-tech.github.io/videos/studio-online/): the online edition, for connected schools. Live teacher casting, classroom control, quizzes, competitions.
- [ZeroAI Studio: a three minute walkthrough](https://zeroai-tech.github.io/videos/studio-walkthrough/): the offline edition, for schools without reliable internet.
- [End-of-life computers, a second life in schools](https://zeroai-tech.github.io/videos/end-of-life-computers/): proof of concept for end-of-life hardware donation requests. Four videos, in attachment order.
